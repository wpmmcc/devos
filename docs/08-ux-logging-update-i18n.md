# 文档 08：交互体验、分层日志、自动更新与多语言规范 (`08-ux-logging-update-i18n.md`)

## 一、免登录与贴合主流 Agent 客户端的 UI / UE 设计

### 1. “零登录”极简首屏体验
- **打开即用**：首次启动直接进入「环境体检 + 新建首个项目」；后续启动自动恢复上次打开的项目和所在标签页。
- **左下角状态区**：放「环境体检灯」、「Agent 连接状态」、「设置与版本更新徽章」，符合主流开发工具习惯。

### 2. 复用主流 Agent 客户端的 5 个操作习惯
| 习惯维度 | 主流 Agent 客户端范式 | DevOS 对应落地设计 |
| --- | --- | --- |
| **视觉质感** | 极简中性灰（Zinc/Slate）+ 1 个主强调色、1px 细边框、默认跟随系统深色/浅色模式 | 原生支持 System / Light / Dark 三态切换，突出红/绿/黄状态灯。 |
| **侧边栏结构** | 左侧可折叠导航（`220px`）+ 顶部主新建按钮 + 底部工具与设置 | 顶部固定「+ 新建项目」，中部放项目列表与 4 个视图入口，底部固定「连接 Agent」「环境体检」「设置」。 |
| **快捷命令面板** | `Cmd/Ctrl + K` 全局唤起搜索与动作 | 支持一键切换项目、启停当前环境、跳转到某条 Issue、打开预览或复制 AI 修复指令。 |
| **非打断式详情** | 列表项点击后从右侧滑出抽屉（Slide-over） | 看板卡片详情、Issue 详情、环境底层日志全部用右侧抽屉承载。 |
| **上下文复制即用** | 提供显眼的「Copy」按钮方便跨工具粘贴 | 任何 Issue、环境报错、提测打回都自带一键复制大白话指令按钮。 |

### 3. 关键节点的交互提示体系
- **跨工具交接提示**：小白提完 Issue 后弹出 Toast 并附带 `[复制指令]` 按钮（如 `请通过 devos 处理 ISS-004`）；Agent 提测后触发桌面通知，点击直接定位到测试台。
- **空状态行动引导**：严禁出现空白页面，无数据时给出清晰操作引导按钮。
- **长耗时阶段反馈**：启动环境或拉取镜像显示分步状态条，超 20 秒提示背景与查看进度入口。
- **危险操作人话兜底**：两句话讲清后果，按钮使用具体动词（如 `[确认还原状态]`）。

## 二、面向小白与排障并重的三层日志系统

| 日志层级 | 目标受众 | 存储与保留策略 | 界面呈现与核心交互 |
| --- | --- | --- | --- |
| **1. 业务动态流（Activity Log）** | 小白用户 | 存在项目 SQLite `activity_events` 表，随项目留存 | 展示在项目概览/右侧动态栏，全大白话时间线，点击跳转对应卡片或 Issue。 |
| **2. 环境与脚本运行日志** | 小白按需查看 + Agent 自动抓取 | 实时流存于内存环形缓冲，同时写入 `<project>/.devos/logs/env.log`（按 10MB 轮转） | 默认折叠在测试台底部。提供「仅看错误」开关与「一键让 AI 诊断报错」按钮。 |
| **3. 应用自身诊断日志** | 客户端排障 / GitHub 提 Bug | Rust `tracing` + `tracing-appender` 按天滚动写入 `~/.devos/logs/app.YYYY-MM-DD.log`（保留 7 天，上限 50MB） | 放在「设置 -> 诊断与日志」中。记录 IPC、MCP 握手、镜像测速与体检日志。 |

### 一键“脱敏诊断包”导出
在「设置 -> 帮助与反馈」提供 `[导出诊断包 (.zip)]` 按钮，自动打包最近 3 天日志 + 系统信息 + 体检报告，强制正则脱敏本地用户名路径、代理密码与敏感 Token。

## 三、基于 GitHub Releases 的应用自动更新设计

利用 Tauri 2 官方 `tauri-plugin-updater` 对接公开仓库 GitHub Releases：
1. **发布与清单**：GitHub Actions 构建多端签名安装包，自动上传 `latest.json` 与 `.sig` 签名。
2. **中国大陆网络加速与安全兜底**：复用 `mirrors.json` 画像拼接加速镜像源，`tauri-plugin-updater` 强制使用官方公钥验签，防劫持篡改。
3. **交互流程**：后台静默检查，左下角小蓝点提示，弹窗查看多语言更新日志，支持重启前安全任务检测。

## 四、全链路多语言（i18n）设计

1. **前端界面层**：`react-i18next` 模块化命名空间管理，首期内置 `zh-CN` 与 `en-US`，支持热切换。
2. **Rust 后端与错误层**：禁止向前端返回写死自然语言，统一返回结构化错误码（`code` + `params`），前端插值渲染。
3. **人机协议与 Agent 输出语言联动**：协议字段与枚举全英文，向 Agent 注入 `user_locale`（如 `zh-CN`），强制要求生成的人类阅读字段符合用户语言。
4. **排版防溢出规范**：按钮标签避免硬编码固定宽度，侧边栏加 `truncate` + Tooltip。
